Assignments change while the centers stay fixed. Then centers move to the coordinate-wise means while assignments stay fixed.

A stable run is not a guarantee of the best possible partition. The companion notebook uses multiple starts and keeps the smallest final inertia.

Algorithm and data details

This dashboard implements Lloyd’s algorithm with squared Euclidean distance. Exact distance ties go to the lowest-numbered cluster. An empty cluster retains its previous center; the interface flags it. A run stops when a reassignment changes no memberships, or after 100 mean updates.

Standardization uses the population standard deviation (ddof = 0), as in scikit-learn’s StandardScaler. A constant feature is mapped to zero. Random starts sample distinct profiles; KMeans++ uses standard D² sampling. The random generator and initialization procedure differ from scikit-learn, so identical seed numbers across implementations need not produce identical starts.

Hourly data are model-based estimates from the Open-Meteo Forecast API’s recent past. They are not independent station readings. Adjacent hours are related in time; these clusters describe the selected period and features, not validated meteorological classes.
