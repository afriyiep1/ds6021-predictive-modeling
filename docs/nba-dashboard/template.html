Interpretation & validation: Models use StandardScaler on 11 numeric variables and OneHotEncoder on home_away inside a scikit-learn Pipeline; transforms are fitted only on training data. Important: Game box-score features are only observed after a game. This analysis is outcome classification, not a pre-game forecast. The requested PTS feature is included, but scoring and other post-game statistics cannot be known before tipoff. The direct outcome proxy +/- is excluded.

Clustering → interpretation: Each observation is a team in one game, not a team across the whole season. Changing raw to standardized changes the distance geometry; that may change the clusters dramatically. K-means and Ward use Euclidean geometry. Silhouette is calculated on all 240 interactive sample rows. Neither method receives the win/loss column. For quick, flexible clustering in a static GitHub Pages site, both methods use the same reproducible sample: 8 rows per team, 240 team-game observations.
