Book guide & references

How to use the book, course texts, and reading guidance.

Module readings use ISL with Python, ESL (2e), Practical Statistics for Data Scientists (2e), Molnar’s online Interpretable Machine Learning, and Introduction to Modern Statistics (2e). Readings are suggested extensions. If you use AI-Assisted Statistics for Data Scientists, locate the matching topics; its chapter numbering may differ. O’Reilly access may require your institutional sign-in.

This book is organized by topic and can be used for guided study or independent review. For an enrolled course, consult Canvas for the current syllabus, policies, staff contacts, office hours, and assessment schedule.

Learn in five connected steps

  1. Understand the question. Identify the outcome, inputs, observational unit, and decision the analysis should support.
  2. Read the mathematics. Connect each expression to a modeling choice and its assumptions.
  3. Inspect the outputs. Read the explanation and saved results; reveal Python when you want to inspect the implementation.
  4. Try an example. Each module includes an editable browser exercise. For the longer notebooks, use Colab and the linked datasets.
  5. Explain and critique. At the end of each module, reveal the optional practice questions. Attempt an answer before opening its suggested explanation.

Reading the book

The six modules progress from data and questions to experiments, linear regression, categorical predictors, interactions and transformations, and generalization. Read them in order for a connected introduction, or use the navigation to revisit a topic.

Suggested readings appear at the end of every module. Start with the core reading, then use the deeper or applied references to explore the ideas further. Chapter numbering depends on the named edition.

Course assignments and independent study

The labs and project provide additional applications. Enrolled students should follow the current instructions in Canvas for deadlines, grading, permitted collaboration, and AI use. Independent readers can use these materials as exercises without a teaching calendar.

Optional chapter practice is for self-study and includes suggested answers. Explain the reasoning in your own words, check units and assumptions, and verify any code you obtain from an AI assistant.

Using the embedded code

  1. Read the explanations, equations, and code cells in each chapter.
  2. Inspect saved notebook outputs, then choose Show Python to reveal their code. Use Run Python in each module for its editable browser exercise.
  3. Choose Run in Colab to open the original notebook, or download its code-only copy.
  4. Get the required CSV from the datasets folder, upload it to Colab’s Files panel, and run the cells in order.
  5. Explain what the fitted model, plot, or comparison means.

Notebook downloads are optional. You can read the notes, code, plots, and labs without leaving the website.
