1.1 Start with an observational unit

A dataset becomes useful when we can say what one row represents. An observational unit is the entity being measured: a student, a customer, a store, or a city at a particular hour. A variable records one characteristic of that unit. Describe the population of interest and how the observed rows were collected before modeling.

In the class survey, a row represents a response. A numeric-looking column is not necessarily quantitative: a category code still describes membership, not an amount. Check types, missing values, impossible values, inconsistent spellings, and duplicated responses. Keep a record of cleaning choices so another person can reproduce them.

From a question to a modeling table

  1. State the question and identify the observational unit.
  2. Describe each column, including its units.
  3. Inspect and clean the data without automatically discarding unusual observations.
  4. Explore distributions and relationships.
  5. Choose the response and identify information available when a prediction must be made.

The following cells illustrate inspection and visualization. Substantive cleaning decisions still require knowledge of how the survey was collected.

From a row to a population claim

Distinguish the observed sample, the population you want to describe, and the future cases on which a model will be used. They need not be the same. A class survey can describe participating students; it cannot automatically represent all UVA students. Likewise, a weather model trained in one season may face a different distribution in another.

For numerical observations x1,…,xnx_1,\ldots,x_nx1​,…,xn​, the sample mean and standard deviation summarize center and spread:

x‾=1n∑ixi,s=1n−1∑i(xi−x‾)2.\overline x=\frac1n\sum_i x_i,\qquad s=\sqrt{\frac1{n-1}\sum_i(x_i-\overline x)^2}.x=n1​i∑​xi​,s=n−11​i∑​(xi​−x)2​.

The standard deviation describes variation among observations. A standard error describes variation in an estimator across samples. They answer different questions. For independent, identically distributed observations with finite variance, the estimated standard error of the mean is s/ns/\sqrt ns/n​.

Interpretation example: If typical sleep varies substantially among respondents, that is a statement about student-to-student variation. A precise estimate of the sample's population mean does not imply that every student sleeps close to that mean.

1.2 Build a dataset from an API

An API returns structured data in response to a request. The notebook requests hourly weather information, receives JSON, and turns the arrays into a pandas table. The practical sequence is request → inspect → organize → check → analyze.

Here, each row is a location–time observation. Temperature, humidity, and precipitation are measurements; the timestamp supplies their temporal context. Check that timestamps and measurements align and that missing values remain identifiable.

Ask which units the service used, which time zone the timestamp describes, and whether values are observations or forecasts. A misleading time label can make a plot wrong even when every line of Python runs successfully.

Preserve the meaning of a measurement

A unit conversion changes numbers without changing the underlying phenomenon. For temperature,

F=95C+32.F=\frac95 C+32.F=59​C+32.

A difference of 1°C is a difference of 1.8°F; the added 32 changes the origin, not the size of a difference. If the response is Fahrenheit rather than Celsius, both the intercept and slope of a regression involving temperature can change. Good column names and labels prevent an apparently correct calculation from having the wrong interpretation.

Record the request parameters, retrieval date, units, and transformations with an API dataset. Reproducibility requires knowing which information was available at the time—not only retaining the final table.

1.3 Visualize, compare, and map

Use plots to answer specific questions. A time plot shows change through a sequence. A scatterplot shows how two measurements vary together. A map adds spatial context, but does not replace a clear time reference.

When combining cities, retain the city identifier on every row. Otherwise, repeated timestamps may be indistinguishable. A grouped summary should specify both the grouping variable and the statistic.

These cells compare six towns and create a map. Association between humidity and temperature does not establish causation. Observations close in space or time may also be dependent; random-row validation is not automatically appropriate for forecasting future weather.

Why correlation is only one view

For paired numerical variables, sample correlation is

r=∑i(xi−x‾)(yi−y‾)∑i(xi−x‾)2∑i(yi−y‾)2.r=\frac{\sum_i(x_i-\overline x)(y_i-\overline y)}{\sqrt{\sum_i(x_i-\overline x)^2\sum_i(y_i-\overline y)^2}}.r=∑i​(xi​−x)2∑i​(yi​−y​)2​∑i​(xi​−x)(yi​−y​)​.

This standardizes a linear association, making it unitless and bounded between −1 and 1 when both variables vary. Near-zero correlation does not rule out a strong curved relationship. A single unusual point can also strongly influence the result.

For the planets data, distance and revolution period are strongly associated, but their scatterplot contains information that a single correlation conceals: the relationship bends. Always connect a numerical summary to a plot and to the scientific question.

The final map takes the last timestamp for each city, including forecast hours. It should not be interpreted as a live observation map.

1.4 Choose the kind of learning problem

Supervised learning

Supervised learning uses examples with a known response YYY and predictors XXX. The fitted rule converts predictors into a prediction:

X⟼f^(X)=Y^.X\longmapsto\widehat f(X)=\widehat Y.X⟼f​(X)=Y.

For regression, the response is quantitative, such as revenue. For classification, it is a category, such as whether a customer purchases. A classifier can estimate probabilities before a decision threshold produces labels.

Unsupervised and reinforcement learning

Unsupervised learning has no designated response label. Clustering groups similar observations; dimension reduction summarizes many variables using fewer coordinates. The definition of similarity and the variable scales matter.

Reinforcement learning studies actions in an environment with rewards and subsequent states. Its sequential feedback differs from predicting a label in a fixed table.

What makes a model useful?

A model must address the question, make useful predictions on new observations, and support appropriate interpretation. Training accuracy alone does not establish generalization. A coefficient is useful only when its interpretation matches the coding and assumptions. Keep three questions together: What did we fit? How did we evaluate it? What can we conclude?

Why squared-error prediction targets a mean

Suppose we predict a constant ccc for cases with predictors X=xX=xX=x. Add and subtract the conditional mean μ(x)\mu(x)μ(x), then expand:

E[(Y−c)2∣X=x]=Var⁡(Y∣X=x)+[μ(x)−c]2.\mathbb E[(Y-c)^2\mid X=x]=\operatorname{Var}(Y\mid X=x)+[\mu(x)-c]^2.E[(Y−c)2∣X=x]=Var(Y∣X=x)+[μ(x)−c]2.

The first term does not depend on our choice of ccc. The second is smallest at c=μ(x)c=\mu(x)c=μ(x). This explains why regression under squared loss aims at a conditional mean. It also shows why perfect prediction may be impossible even with the correct mean function: outcomes still vary around that mean.

A different loss can change the target. Absolute-error prediction targets a conditional median. Therefore, “best prediction” is incomplete without saying how errors are measured.

Book connection: ISL introduces the learning problem and the role of error; IMS connects it to how observations were collected. Read those perspectives together: a sophisticated model cannot repair a population mismatch merely by fitting the observed sample well.

Why might a numerical-looking column have an object dtype?

Reveal explanation

A mixture of numbers and text, inconsistent formatting, or special missing-value markers can cause a column to be read as text. Inspect the entries before converting; coercion can create missing values.

Optional practice questions

Want more practice? Try these questions after reading the chapter. They are for self-study; work through your reasoning before revealing an answer.

Reveal 5 practice questions

  1. Define the prediction task

    A weather service wants to predict rain in Charlottesville tomorrow using hourly records from several cities. What is one observational unit, what is the response, and which inputs would be available when the prediction is made? Identify one input that would leak the answer.

    Reveal suggested answer

    One suitable unit is a city–day, with an indicator of rain on the following day as the response. Inputs could include weather observed up to the prediction time and forecasts issued by that time. Tomorrow's measured precipitation would leak the outcome. State the forecast horizon and distinguish an issued forecast from a later observation.

  2. Inspect before converting

    A sleep-hours column contains 7, 6.5, seven, and an empty entry and loads as object. Why is its dtype insufficient to decide whether it is a numerical variable? What would you inspect before converting it?

    Reveal suggested answer

    Dtype describes storage, not scientific meaning. Sleep duration is numerical even when text values prevent numeric storage. Inspect unique values, missingness, units, and implausible ranges. An unambiguous entry such as seven can be recoded with a documented rule; treating every failed conversion as missing without inspection can hide errors.

  3. Choose an informative plot

    Using the planets dataset, propose one plot to describe orbital distance alone and another to explore how orbital period changes with distance. What can the second plot reveal that a correlation coefficient might conceal?

    Reveal suggested answer

    A histogram or dot plot describes distance. A scatterplot of revolution period against distance displays their relationship. The scatterplot can reveal curvature, isolated observations, and uneven spacing that a single correlation coefficient does not describe. Axis labels should include the file's units.

  4. Make an API dataset usable

    An API returns temperature in Celsius, wind speed in km/h, and a numerical weather code. You convert temperature to Fahrenheit. What should change in the column name and documentation? Why should a weather-code average be treated cautiously?

    Reveal suggested answer

    Use an explicit name such as temperature_f, document the conversion F = 1.8C + 32, and retain the meaning of the other units. Weather codes identify conditions; their numeric labels do not necessarily have meaningful distances. Frequencies by condition are generally more interpretable than their average.

  5. Try a small data audit

    Open the fictional survey dataset. Identify one missing-value issue and one inconsistent category, propose a cleaning rule for each, and explain how your rule could change a summary. You may use the module's Python example to inspect the data.

    Reveal suggested answer

    For example, blank sleep values require an explicit missing-data decision, and iPhone and iphone can be standardized to one label. Standardizing merges category counts. Dropping missing sleep values changes both the sample size and the population represented by a mean; report the denominator and justify the choice. Several valid audits are possible.
