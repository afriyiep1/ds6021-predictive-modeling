# DS 6021: Introduction to Predictive Modeling

An open reading edition of Prince Afriyie's UVA course: six HTML modules, typeset equations, original class notebook code and saved outputs, editable Python examples, labs, and textbook reading guides.

## Publish with GitHub Pages

In Settings → Pages, choose **Deploy from a branch**, **main**, and **/docs**. Save. The site will appear at the GitHub Pages URL reported by GitHub. No build service, Python server, or ChatGPT account is needed to read it.

## Public data

The survey fixture is entirely fictional. The original class survey, PDF files containing course form links, private Git history, and TA contact details are excluded. The other supplied course datasets remain available. Notebook downloads contain code only.

## Running Python

Every module includes one editable, self-contained exercise. The first run downloads Pyodide 0.27.7 and scientific packages from jsDelivr; Python executes locally in a Web Worker. Stop terminates the worker. Default outputs remain readable without starting Python. Full notebooks can be opened in Colab; API-based notebooks may require network access there. Browser edits are temporary.

## Textbook connections

Readings refer to ISL with Python (2023), ESL (2e), Practical Statistics for Data Scientists (2e), Molnar's online Interpretable Machine Learning, and Introduction to Modern Statistics (2e). The book links to these sources; their full texts are not redistributed.

## Updates

This is the generated public edition. Edit the maintained course Markdown/notebooks, run the course build and public export, then replace /docs and commit. Relative asset paths support project Pages and custom domains. Local KaTeX and Plotly retain their respective third-party licenses; Pyodide packages retain theirs.
